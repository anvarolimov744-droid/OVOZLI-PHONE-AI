# OVOZLI PHONE AI

Ovozli boshqaruv sayti (HTML/CSS/JavaScript) va Android Studio manba loyihasi.

## GitHub Pages

1. `index.html`, `style.css`, `script.js` fayllarini repository root qismiga joylang.
2. GitHub repository → Settings → Pages.
3. Deploy from a branch → `main` → `/ (root)` → Save.
4. Sayt HTTPS manzilda ochiladi. Mikrofon uchun brauzer ruxsati kerak.

## Android ilova

`android-app/` ichidagi loyiha Android Studio orqali APK qilib yig'iladi. GitHub Pages saytining o'zi Android fon xizmatini ishga tushira olmaydi.
